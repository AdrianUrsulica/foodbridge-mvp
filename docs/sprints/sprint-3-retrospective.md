
# FoodBridge – Sprint 3 Retrospective

**Sprint period:** 17–30 November 2026  
**Prepared:** 24 November 2026  
**Status:** Team feedback confirmed – 24 November 2026

## 1. What Went Well

- All five Sprint 3 issues were completed.
- GitHub pull requests supported code review and collaboration.
- The food listing functionality was integrated successfully.
- All 89 automated Django tests passed on main.
- Manual testing helped identify three low-severity defects.
- Jira provided visibility of task progress and responsibilities.

## 2. What Could Be Improved

- Some tasks were carried over from Sprint 2, affecting the original schedule.
- GitHub merge conflicts required additional integration work.
- Earlier communication about task progress could reduce delays.
- Testing and integration should happen throughout the sprint rather than mainly towards the end.

## 3. Proposed Action Items for Sprint 4

1. Review progress regularly and communicate blockers early.
2. Submit pull requests as soon as features are ready.
3. Continue reviewing and testing code before merging.
4. Track and resolve the three documented defects.
5. Prioritise mandatory MVP requirements over optional features.
6. Aim to complete implementation and testing by 18 December 2026.
